# Project Requirements

## Functional Requirements

1. The system shall allow a registered user to log in.
2. The system shall allow a user to submit a disaster relief resource request.
3. The system shall store resource requests in the database.
4. The system shall allow available resources to be added.
5. The system shall display submitted requests on the dashboard.
6. The system shall allow request status to be changed.
7. The system shall allow the user to log out.

## Non-Functional Requirements

1. The application should be easy to use.
2. The application should respond quickly for normal operations.
3. The application should validate required input.
4. Passwords should be stored as hashes.
5. The application should be containerizable using Docker.
6. The application should be maintainable through modular files.
